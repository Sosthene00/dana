# Encrypted File Backup — Test Vectors (format v1)

Spec §9 compliance vectors for `docs/specs/encrypted-file-backup.md`
(ratified v1.0, commit 0592280). Generated BY the reference
implementation (`rust/src/backup_vectors.rs`) from a fixed set of test
keys — never hand-computed. Vectors 4/5/5a are defined mutations of
vector 2.

Files: one JSON artifact per vector (machine-readable, the canonical
checked-in form), plus `bip139-test-vectors-draft.md`, the draft text
block for upstream publication against the BIP-139 draft (the owner
posts it upstream; nothing here writes to GitHub).

| file | §9 vector | title | expected |
|---|---|---|---|
| `vector-1.json` | 1 | Minimal payload | decrypt_success |
| `vector-2.json` | 2 | With secrets block (standard two-section file) | decrypt_success |
| `vector-3.json` | 3 | With optional section (all three sections) | decrypt_success |
| `vector-4.json` | 4 | Wrong-password decryption failure | decrypt_error (AuthenticationFailed) |
| `vector-5.json` | 5 | Corrupted-header-AAD decryption failure — corrupted header AAD (argon2_t) | decrypt_error (AuthenticationFailed) |
| `vector-5a.json` | 5 (companion) | Companion: corrupted magic bytes — corrupted magic (early parse-reject) | decrypt_error (BadMagic) |

Each artifact states: Argon2id params, salt, nonce, cipher_id, and the derived
AEAD key (for KDF-drift debugging), plus full file hex, header hex, and plaintext
hex.

Regeneration: `DANA_VECTOR_OUT=docs/backup-test-vectors cargo test --lib
generate_artifacts -- --ignored` from `rust/`. The test
`backup_vectors::tests::checked_in_vectors_regenerate_byte_identical` asserts
byte-identity of every checked-in artifact with the reference implementation on
every test run.
